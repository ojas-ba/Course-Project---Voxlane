# PHASE 0 DOCS CLEANUP

## Goal

Create a clean documentation hierarchy and preserve legacy docs in archive.

## Scope

- Build docs/current, docs/plans, docs/decisions, and docs/archive structure.

## Out Of Scope

- Any runtime/service code change or behavior modification.

## Files Likely Affected

- `docs/`, root `README.md`, `AGENTS.md` note, archived markdown files.

## Acceptance Criteria

- New docs hierarchy exists and old docs remain preserved under archive.
